# medifee.keywordegg.com

건강보험이 적용되지 않는 **비급여 진료비**를 항목별·지역별로 보여주는 사이트.
yoyang·sanhu 와 같은 스택(Next.js + Supabase + Cloudflare)과 같은 UI 스킨을 쓴다.

---

## 이 사이트가 무엇을 말하고 무엇을 말하지 않는가

**원 단위 금액을 한 글자도 싣지 않는다.** 원본의 가격 적용일자가
2015년(92%)·2016년(8%)이라 절대 금액은 이미 틀렸다. 그대로 실으면 맞지 않는
숫자를 현재 가격처럼 보이게 만든다.

그럼에도 만든 이유가 있다. 금액을 빼도 남는 것이 있어서다.

> 비급여는 건강보험 수가가 없어 **병원이 스스로 가격을 정한다.**
> 그래서 같은 항목도 몇 배씩 차이 난다. 소견서 **300배**, 진료확인서 100배,
> 추나요법 80배, 복합레진 38배, 일반진단서 25배.

**배수와 상대적인 순서**는 절대 금액과 달리 시간이 지나도 크게 뒤집히지 않는다.
그래서 화면은 이렇게만 말한다.

- 이 항목은 병원마다 **몇 배** 차이 나는가
- 어떤 **종별**이 상대적으로 비싼가 (전체 평균 대비 %)
- 어떤 **지역**이 상대적으로 비싼가 (전국 평균 대비 %)

실제 금액은 심평원 조회로 넘긴다. 이 방침을 어기면 사이트가 거짓말을 하게 된다.
`lib/price-data.ts` 에 금액 표시 함수(formatWon 같은 것)를 두지 않는 이유다.

## URL 구조

| 경로 | 화면 |
|---|---|
| `/` | 홈 — 차이가 가장 큰 항목 |
| `/항목` | 항목 허브 (대분류 14개) |
| `/일반진단서` | 항목 상세 — 최저·최고 병원, 지역별 평균 |
| `/지역` | 지역 허브 |
| `/서울-강남구` | 지역 상세 — 항목별 가격 |
| `/about` `/contact` `/privacy` `/terms` | 안내 |

`app/[slug]/page.tsx` 하나가 네 화면을 맡는다.
**지역을 항목보다 먼저 찾는다.** 지역 슬러그는 우리가 정한 고정 목록이고 항목
슬러그는 원본에서 나오므로, 순서를 뒤집으면 언젠가 항목 이름이 지역을 가린다.

## 데이터

공공데이터포털 **15001700** 「건강보험심사평가원_비급여진료비정보조회서비스」
<https://www.data.go.kr/data/15001700/openapi.do> · 자동승인 · XML · 무료

오퍼레이션은 `getNonPaymentItemHospList` 하나만 쓴다. 포털 설명에 있는
`비급여진료비용지역별정보`는 이름을 찾지 못했다(여러 후보로 호출해도
"해당 오픈API 서비스가 없거나 폐기됨"). 지역별 집계는 우리가 직접 낸다.

```bash
npm run probe:prices     # 한 페이지만 받아 구조 확인
npm run import:prices    # 전체 적재 + 집계 갱신
```

### 실측으로 확인한 것 (14,058건 전수)

| 항목 | 값 |
|---|---|
| 가격 자료 | 12,942건 (지역 매칭 실패분 제외) |
| 병원 | 576곳 — **병원급 이상만. 의원급 없음** |
| 항목 | 52개 / 대분류 14개 |
| 지역 | 152개 시군구 |
| **가격 적용 연도** | **2015년 92% · 2016년 8%** |

### 지역 매칭에서 겪은 것

심평원 지역 표기가 표준 행정구역과 다르다. 매칭률 97.5%까지 올리는 데 세 가지가 필요했다.

- **`전남광주`** — 두 시도를 합쳐 놓은 값이 있다. 하나로 못 정하고 후보를
  여러 개 놓은 뒤 시군구로 판별한다
- **정확 일치를 먼저 본다** — 접두어부터 떼면 `부산진구`가 `부산`+`진구`로
  잘려서 없는 지역이 된다 (실제로 겪었다)
- **일반구 합치기** — `고양일산동구` → `고양시`, `수원팔달구` → `수원시`

남은 3종은 전부 2026년 인천 개편(제물포구·서해구·검단구)이라 `data/regions.json`
에 추가했다. 옛 이름도 남겨 두었다 — yoyang·sanhu 는 옛 이름 자료를 쓴다.

### 항목 식별

`itmCdNm`(항목명)은 병원이 자유롭게 적어서 5,000가지가 넘는다. 그걸로 묶으면
페이지가 폭발하고 같은 항목이 쪼개진다. 심평원이 코드로 관리하는
`divCd1~3` 을 쓰면 52개로 정리된다.

## 지켜야 할 원칙

- **원 단위 금액을 화면에 넣지 않는다.** 배수와 퍼센트로만 말한다.
  새 화면을 만들 때 이걸 어기기 쉬우니 주의할 것
- **왜 금액이 없는지 밝힌다.** 설명이 없으면 "가격 사이트인데 가격이 없다"로만
  읽힌다. DataNotice 가 모든 화면 하단에서 그 역할을 한다
- **가격 차이를 품질 차이로 말하지 않는다.** 의료광고로 읽힐 여지를 만들지 않는다
- **병원을 추천하거나 순위를 매기지 않는다.** 심평원처럼 분포만 보여주고 판단은 넘긴다
- **자료가 없는 지역은 noindex.** 병원급 이상만 담긴 자료라 빈 지역이 많다

## 개발

```bash
npm install
npm run dev
npm run lint && npm run build
npx wrangler login && npm run cf:deploy
```

Supabase 는 keywordegg 계열과 같은 프로젝트를 쓰고 테이블 접두사(`medifee_`)로만
나눈다. 애드센스 퍼블리셔도 같은 계정이라 재승인이 필요 없다.
슬롯만 이 사이트용으로 만들어 `lib/ads.ts` 에 넣으면 된다.
